# Écrans manquants par lot

## Lot 1 — Socle : couverture actuelle

Les maquettes actuelles couvrent bien le socle de navigation, les tableaux de bord et les parcours métier principaux du lot 1 :

- accueil / tableau de bord général,
- navigation par espace (formateur, maintenance, direction pédagogique, admin),
- écrans de pointage,
- écrans de maintenance,
- écrans de rapport / cahier de texte,
- écrans de supervision et de suivi.

Ce qui manque encore dans le lot 1 :

- écran de connexion / ouverture de session,
- écran d’activation du compte après invitation,
- écran de réinitialisation / mot de passe oublié,
- écran de choix de rôle ou de redirection après connexion,
- écran de gestion des permissions et de l’état du compte.

## Lot 2 — RH

### 1. Ecran d’invitation et activation du compte
Description : écran permettant d’inviter une recrue, de joindre les informations du compte, d’envoyer le lien d’activation et de suivre l’état de l’activation.

### 2. Ecran de profil recrue / fiche RH
Description : vue complète d’un collaborateur avec photo, CV, CNI, statut, contrat, rôle, acceptation du règlement intérieur, historique RH et pièces jointes.

### 3. Ecran de validation des documents RH
Description : liste des recrues avec pièces à vérifier, statut “en attente”, “accepté”, “rejeté”, bouton de validation ou demande de correction.

### 4. Ecran d’acceptation du règlement intérieur
Description : affichage de la version en vigueur du règlement, case d’acceptation, historique des versions et validation par l’utilisateur.

### 5. Ecran de désactivation / archivage d’un compte
Description : action d’inactivation ou d’archivage d’un collaborateur avec justificatif, motif et impact sur les accès.

### 6. Ecran de liste des personnels / administrateurs
Description : tableau complet avec filtres par rôle, statut, école, et actions de gestion, en vue admin RH et super-admin.

---

## Lot 3 — Pointage

### 1. Ecran de configuration des écoles et créneaux
Description : gestion des écoles, salles, créneaux, fenêtres horaires, rayon de géolocalisation, codes de présence et règles de tolérance.

### 2. Ecran de pointage en cours
Description : écran principal du formateur pendant le pointage, avec vérification de la position GPS, du code, de la date et de l’heure dans la bonne fenêtre.

### 3. Ecran de validation / rejet du pointage
Description : écran affichant le statut du pointage après validation, retard, départ anticipé, hors zone, ou à vérifier, avec justificatif possible.

### 4. Ecran d’historique de pointage par formateur
Description : liste des pointages passés, avec détails par date, école, salle, créneau, statut, retard, justification et éventuelle correction.

### 5. Ecran des absences et anomalies
Description : visualisation des pointages non effectués, anomalies géolocalisation, retards, et actions de suivi par la direction ou l’administration.

---

## Lot 4 — Rapports journaliers

### 1. Ecran de création d’un rapport de séance
Description : formulaire de rapport avec objet, contenu, interventions, objectifs, observations, et enregistrement en brouillon ou en soumission.

### 2. Ecran de suivi des rapports par statut
Description : tableau visuel des rapports “brouillon”, “soumis”, “à modifier”, “validé”, “validé avec corrections”, avec filtres par formateur et date.

### 3. Ecran de validation / correction de la direction
Description : lecture d’un rapport soumis, commentaires de la direction, décisions “valider”, “demander une modification”, “refuser”, avec saisie de commentaires obligatoires.

### 4. Ecran d’historique des révisions
Description : journal des corrections apportées à un rapport, avec version, auteur, commentaire et date de modification.

### 5. Ecran de gestion du cahier de texte / planning de cours
Description : vue de la programmation, des séances et des rapports associés, pour assurer le suivi du cahier de texte et l’édition de documents pédagogiques.

### 6. Ecran de notifications et relances
Description : liste des rappels, demandes de correction, notifications pour les formateurs et les responsables pédagogiques.

---

## Lot 5 — Maintenance

### 1. Ecran d’inventaire du parc informatique
Description : liste des machines, ordinateurs, switchs, postes, salles, statuts, affectation, historique de maintenance et recherche par équipement.

### 2. Ecran de création d’un ticket de panne
Description : formulaire de signalement d’une panne avec poste, machine, type de problème, photo, localisation, description, priorité et assignation.

### 3. Ecran de suivi des tickets par statut
Description : vue globale des tickets ouverts, en cours, résolus, avec filtres par priorité, salle, technicien et date.

### 4. Ecran de détail d’un ticket technique
Description : panneau complet pour un ticket avec informations, historique, pièces jointes, commentaires, affectation, actions, durée et résolution.

### 5. Ecran de maintenance d’un poste / machine
Description : fiche technique du matériel, interventions passées, pièces remplacées, pièce de rechange, date de maintenance et état global du poste.

### 6. Ecran de statistiques de maintenance
Description : indicateurs de disponibilité, temps moyen de réparation, tickets urgents, taux de résolution, et suivi par salle ou par type de machine.

---

## Lot 6 — Bilans et partenaires

### 1. Ecran de sélection de période de bilan
Description : choix hebdomadaire ou mensuel, établissement concerné, période, type de bilan, et filtre par école ou formateur.

### 2. Ecran de génération de bilan
Description : assemblage des rapports validés, aperçu du contenu, calculs de statistiques, export Word, PDF et prévisualisation avant envoi.

### 3. Ecran de portail partenaire
Description : vue école partenaire avec bilans, fiches de suivi, indicateurs clés, lecture seule, et visualisation des documents transmis.

### 4. Ecran d’envoi et publication du bilan
Description : écrans de finalisation, signature, envoi vers l’école, validation finale et historique des documents diffusés.

### 5. Ecran de gestion des signatures et logos
Description : personnalisation des modèles de bilans avec logo, signature, nom de l’école, mention de la direction, et versions finales figées.

### 6. Ecran de suivi du portail partenaire
Description : historique des bilans envoyés, statut “envoyé”, “vu”, “validé”, “non lu”, avec journal d’actions de diffusion.

---

## Synthèse

Le volume des maquettes existantes est bien adapté au lot 1 et aux parcours opérationnels visibles. Les écrans manquants correspondent surtout aux lots 2 à 6, qui sont précisément les lots RH, pointage avancé, rapports, maintenance et bilans partenaires décrits dans le cahier des charges.
